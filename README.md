# Portal UNH — prévia móvel pública (somente interface)
Esta branch contém APENAS páginas HTML/CSS/JS e imagens de apresentação.
Os indicadores e os equipamentos são **fictícios** (DEMO-001, DEMO-002, DEMO-003).

- Não é a intranet oficial.
- Não utiliza PostgreSQL, APIs, LDAP ou outros recursos da UNH.
- Não recebe arquivos; upload desativado.
- Não contém senhas, tokens, relatórios, números de série reais ou informações privadas.
- Qualquer pessoa com o endereço pode visualizar esta demonstração.
- Não usar para operação institucional.
- A versão institucional está em outra branch e sob infraestrutura da TI.

Para publicar: GitHub > Settings > Pages > Deploy from a branch > gh-pages > /(root) > Save.
